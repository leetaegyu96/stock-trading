# v1.5.0 — 2026-07-09

**시장지수 추세 필터(하락장 가드) — opt-in 전략 튜닝.** 서브프로젝트 6. 시장 지수가 하락
추세(20일선 아래)일 때 해당 시장의 신규 매수를 차단하는 가드를 추가했다. **기본 비활성(default
OFF)** — 기존 동작은 전혀 바뀌지 않으며, `--bear-guard`로 켠다. 6개월 리플레이 A/B로 효과를 검증·기록했다.

## Added

- **하락장 가드** (`TradeRules.bear_market_guard`, 기본 False): 시장 대표 지수(KR=코스피200,
  US=S&P500)의 20일 이동평균 대비 종가가 아래면 그 시장의 **신규 매수만 차단**. 보유·매도·손절·
  트레일링·부분매도·쿨다운은 그대로 작동. `simcore/engine.py::evaluate_close(market_bearish=...)`.
- **지수 로더** (`simcore/data.py::load_index`): KR=pykrx 코스피200(1028), **KRX 자격증명 없거나
  실패 시 yfinance `^KS200`로 폴백**; US=yfinance `^GSPC`. 캐시.
- **리플레이 연동**: `DataBundle.kr_index/us_index`, `run_replay`가 시장별·일자별 하락장 플래그를
  계산해 엔진에 전달. `SignalParams.market_trend_period=20`.
- **CLI `--bear-guard`**: 가드 활성화. 지수는 가드 활성 시에만 로드.

## Changed

- `docs/trading-rules.md`에 "하락장 가드" 절 추가, README에 `--bear-guard` 안내.

## Fixed

- `load_index` KR 경로가 KRX 자격증명 없을 때 크래시하던 문제 → yfinance `^KS200` 폴백.
- 지수 로드를 `--bear-guard` 활성 시로 한정 → 기본(OFF) 실행에 불필요한 지수 로드·크래시 표면 제거.

## 검증 (6개월 A/B, 2026-01-09~07-09, 폴백 유니버스 KR30/US30)

| 캐릭터 | TWR OFF→ON | MDD OFF→ON | 평가 |
|---|---|---|---|
| 해외형 | +16.1% → **+26.9%** | −11.0% → **−6.5%** | 개선(가드 유효) |
| 국내형 | +38.9% → +30.4% | −17.3% → −15.7% | 중립(MDD↓·수익↓) |
| 범용형 | −12.1% → **−17.1%** | −25.7% → **−34.7%** | 악화(목표 미달) |

- **정직한 결론**: 가드는 **해외형에 유효**(TWR·MDD·승률 개선), **범용형에는 역효과**(신규매수를
  막는 동안 손실 포지션을 갈아타지 못해 집중도·MDD 상승). 목표였던 범용형 개선은 이번 설정에선
  달성 못함. 기본 OFF이므로 위험 없이 opt-in 도구로 제공하고, 튜닝 방향(회전매수 예외·범용형은
  양시장 동시 하락 시만·MA 기간·캐릭터별 롤아웃)을 실험 기록에 남겼다.
- pytest 198 통과. 서브에이전트 구동 개발 + 최종 전체 리뷰(opus) READY TO MERGE.

## 알려진 사항 / 후속

- 가드를 상시 켜려면(특히 범용형) 위 튜닝 선행 필요 — 현재는 해외형 우선 적용 권장.
- 라이브 지수 실시간 피드 연동 미구현(리플레이 A/B 용도). 라이브는 기본 OFF로 동작 무변경.
- 유니버스는 폴백 top-30(KRX 자격증명 부재) — 절대 수치 일반화는 제한적.
