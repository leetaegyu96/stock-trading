# 매매 규칙서 (trading-rules)

이 문서는 시뮬레이터의 매매 판정 로직 **단일 기준 문서**다.
`simcore/config.py` 의 모든 설정값과 1:1 대응하며, 설정을 바꾸면 이 문서도 함께 갱신한다.
코드를 읽지 않아도 이 문서만으로 "왜 이 종목을 샀는지/팔았는지" 재구성 가능해야 한다.

- 최종 갱신: 2026-07-07 (초기 설계값)
- 튜닝 이력: 실험 결과는 `docs/experiments/` 참조

## 1. 판정 주기와 체결 규칙

| 단계 | 시점 | 하는 일 |
|---|---|---|
| 신호 판정 | 일봉 확정 시 (장 마감 후) | 유니버스 전 종목 청/적신호 카운트 → 매수/매도 예약 |
| 신호 주문 체결 | **다음 거래일 시가** | look-ahead bias 방지를 위해 당일 체결 금지 |
| 손절/익절 | 장중 5분마다 (라이브) / 일중 OHLC 근사 (리플레이) | 신호와 무관하게 즉시 체결 |

리플레이 일중 근사: 당일 저가 ≤ 손절가 → 손절, 당일 고가 ≥ 익절가 → 익절.
둘 다 해당하면 **손절 우선** (보수적 처리).

## 2. 청신호 10개 (매수 신호, 일봉 기준)

거래량 평균·전고점 기간 등 괄호 안 숫자는 모두 설정값이다.

| # | 이름 | 판정 조건 (당일 = 방금 확정된 일봉) | 상태 |
|---|---|---|---|
| G1 | 골든크로스 | SMA(5) > SMA(20) | 활성 |
| G2 | 추세 위 | 종가 > SMA(20) | 활성 |
| G3 | RSI 50 상향 돌파 | 전일 RSI(14) ≤ 50 이고 당일 RSI(14) > 50 | 활성 |
| G4 | MACD 골든 | MACD(12,26) > 시그널(9) | 활성 |
| G5 | 거래량 급증 양봉 | 거래량 ≥ 20일 평균 거래량 × 1.5 이고 종가 > 시가 | 활성 |
| G6 | 볼린저 중심 돌파 | 전일 종가 ≤ BB(20,2) 중심선 이고 당일 종가 > 중심선 | 활성 |
| G7 | 전고점 돌파 | 종가 > 직전 60거래일 최고 종가 (당일 제외) | 활성 |
| G8 | 긍정 심리 급증 | 뉴스·커뮤니티 감정분석 (인터페이스만 존재) | **스텁 (항상 꺼짐)** |
| G9 | 외인·기관 순매수 | 수급 데이터 (인터페이스만 존재) | **스텁 (항상 꺼짐)** |
| G10 | 스토캐스틱 반등 | 전일 %K(14,3) < 20 이고 당일 %K가 %D(3) 상향 돌파 | 활성 |

## 3. 적신호 10개 (매도 신호 — 보유 종목에만 적용)

롱 온리: 미보유 종목의 적신호는 무시한다. 숏 진입 없음.

| # | 이름 | 판정 조건 | 상태 |
|---|---|---|---|
| R1 | 데드크로스 | SMA(5) < SMA(20) | 활성 |
| R2 | 추세 아래 | 종가 < SMA(20) | 활성 |
| R3 | RSI 과매수 후 꺾임 | 전일 RSI(14) ≥ 70 이고 당일 RSI < 전일 RSI | 활성 |
| R4 | MACD 데드 | MACD(12,26) < 시그널(9) | 활성 |
| R5 | 거래량 급증 음봉 | 거래량 ≥ 20일 평균 × 1.5 이고 종가 < 시가 | 활성 |
| R6 | 볼린저 하단 이탈 | 종가 < BB(20,2) 하단밴드 | 활성 |
| R7 | 손절 도달 | 현재가 ≤ 평단가 × (1 − 7%) — 카운트와 무관하게 **즉시 강제 청산** | 활성 |
| R8 | 부정 심리 급증 | 감정분석 (인터페이스만 존재) | **스텁 (항상 꺼짐)** |
| R9 | 외인·기관 순매도 | 수급 데이터 (인터페이스만 존재) | **스텁 (항상 꺼짐)** |
| R10 | 익절 도달 | 현재가 ≥ 평단가 × (1 + 15%) — **즉시 청산** | 활성 |

## 4. 임계값

| 항목 | 값 | 비고 |
|---|---|---|
| 매수 임계값 | 청신호 ≥ **7** | 스텁 3개가 꺼진 동안은 사실상 "기술 신호 전부"라 매우 엄격함. 리플레이 튜닝 시 5 등으로 낮춰 실험 가능 |
| 매도 임계값 | 적신호 ≥ **3** | 보유 종목만 |
| 손절 | 평단 대비 **−7%** | 즉시, 카운트 무관 |
| 익절 | 평단 대비 **+15%** | 즉시 |

## 5. 포지션 사이징 · 우선순위

- 최대 보유: 캐릭터당 **5종목**.
- 1종목 배분: `가용 현금 ÷ 남은 슬롯 수` 균등 배분.
- 매수 우선순위: 청신호 개수 많은 순 → 당일 등락률 높은 순 → 거래량 많은 순.
- 현금 부족 시 매수 스킵. 매도로 현금이 생기면 다음 판정 주기에 후보 매수.
- 이미 보유 중인 종목 재매수 금지.
- **쿨다운**: 매도한 종목은 **2거래일** 재매수 금지.

## 6. 비용 모델

| 항목 | 값 | 적용 |
|---|---|---|
| 국내 매매 수수료 | 0.015% | 매수·매도 각각 |
| 국내 증권거래세 | 0.15% | 매도 시 |
| 미국 매매 수수료 | 0.09% | 매수·매도 각각 |
| 환전 수수료 | 0.1% | KRW↔USD 환전 시 |
| 슬리피지 | 0% | on/off 스위치 있음 |

## 7. 캐릭터 구성

| 캐릭터 | 유니버스 | 통화 | 초기 자금 | 거래시간 |
|---|---|---|---|---|
| 국내형 | 코스피200 | KRW | 1억 원 | KRX 09:00–15:30 KST |
| 해외형 | S&P500 | USD | 1억 원 (시작 시점 환율 환전) | 미국장 (서머타임 반영) |
| 범용형 | 코스피200 + S&P500 | 혼합 | 1억 원 | 각 시장 개장시간 |

세 캐릭터의 규칙·임계값은 동일하되, 설정에서 캐릭터별 오버라이드 가능
(예: 공격 6 / 표준 7 / 보수 8 — 향후 확장).
