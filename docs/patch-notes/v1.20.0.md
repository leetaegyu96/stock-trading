# v1.20.0 — 2026-09-28

v2 착수에 따른 **경로 분리**. 기능 변경은 없다.

## Changed

- 공개 URL 이 `/stock-trading/` → **`/stock-v1/`** 로 이동. 기존 경로는 **301 영구 이동**으로
  보존되므로 북마크는 그대로 동작한다.
- 프론트는 `VITE_BASE_PATH=/stock-v1/` 로 재빌드해야 한다(자산 경로가 프리픽스를 포함).

## Fixed

- nginx 에 `absolute_redirect off` 추가. 이 nginx 는 앞단 Caddy 뒤에서 평문 80 으로 받기
  때문에 절대 리다이렉트를 만들면 `Location` 이 `http://` 로 나가 브라우저가 https 로 한 번 더
  튕겼다. 상대 경로 리다이렉트로 두어 클라이언트가 현재 스킴을 유지한다.

## Added

- `v2/` — 회원제 수동매수 + 매도벽 모의투자(별도 서비스 :8030, `/stock-v2/`).
  이번 릴리즈에는 스펙·계획·기반 모듈만 포함된다.
  - `v2/docs/SPEC.md` — 계약서(도메인·API·화면·테스트 목표)
  - `v2/docs/PLAN.md` — 구현 계획
  - `v2/backend/{settings,money,models,db}.py` — 설정·정수 금액·ORM 9테이블·세션
  - DB `simcore_v2` / `simcore_v2_test` 생성
  - `pyproject.toml` 에 argon2-cffi, PyJWT 추가

## 운영 영향

v1 은 경로만 바뀌었고 매매 동작·설정은 불변(`INTRADAY_ENABLED=0`,
`SIGNAL_SELL_ENABLED=false`, `MAX_POSITIONS=10`, `TRAILING_INTRADAY_UPDATE=false`).
