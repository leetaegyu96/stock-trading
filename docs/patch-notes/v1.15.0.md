# v1.15.0 — 2026-07-21

**장중 스캔 관측성: 스캔이 돌고 있는지·종목별로 왜 샀/안 샀/팔았는지 대시보드에서 실시간으로 보인다.**

## 배경

장중 자동매매(intraday)를 켜도 매매가 없으면 대시보드에서 "돌고 있는지"조차 확인할 수
없었다. 또 상단 "실시간 · HH:MM:SS" 표기는 실제로는 (1) WebSocket 연결 여부와 (2) 브라우저가
마지막으로 카드 스냅샷을 받은 시각이라, 시장 데이터/스캔 시각으로 오해할 소지가 있었다.

## Added

- **스캔 하트비트 (`intraday_scan` 테이블 + `/api/scan-status`).** 매 장중 스캔마다(0건 매매·
  전 종목 조회 실패 포함) "언제·시도/평가/실패 종목 수·매수게이트 통과 수·매수/매도 건수·스캔
  주기"를 시장별 최신 1행으로 남긴다. **전 종목 조회가 실패해도** 조용히 빠지지 않고 하트비트를
  남긴다(v1.14.1 토큰 만료와 같은 "조용한 실패" 계열 방지).
- **스캔 상태 스트립 (`ScanStatusStrip`).** 대시보드 상단에 "KR 13:43 · 58/60종목(실패 2) ·
  게이트통과 3 · 매수 1/매도 0 · 다음 ~10분"처럼 표시. 스캔 기록이 없으면 "대기 중 (가동 전이거나
  INTRADAY OFF)"로 명시(조용히 생략하지 않음).

## Changed

- **의사결정판이 장중에도 갱신된다.** 종목별 청/적신호·매수게이트·차단사유(오늘의 후보)는 기존에
  장 마감 때만 갱신됐으나, 이제 매 장중 스캔마다 갱신되어 "왜 안 샀는지"가 실시간으로 보인다.
  `evaluate_intraday`가 후보 평가(status/block_reason)를 기록: 보유중·쿨다운·점수부족·게이트미충족·
  슬롯부족·**체결강도미달·장중매수캡·재매수쿨다운·킬스위치**·현금부족, 성공 시 `status=매수`.
- **"실시간" 라벨 정정.** 연결 표시를 "실시간"→"연결됨"으로 바꿔 소켓 연결 상태임을 명확히 하고,
  상단 시각에는 "카드 갱신" 라벨을 붙여 시장 데이터/스캔 시각이 아님을 드러낸다(ModeBar 동일).

## 안전/불변식

- 엔진 변경은 장중 **체결 결과(종목·수량·시점)를 바꾸지 않는다** — 후보 평가는 관찰 전용 기록만
  추가한다. `_intraday_can_buy`는 사유를 돌려주는 `_intraday_buy_block` 재사용으로 리팩터(동작 불변).
- 기존 `on_close`/리플레이/시딩 경로 동작 불변. 신규 테이블은 `create_all` 자동 생성(마이그레이션 없음).
