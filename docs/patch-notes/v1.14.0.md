# v1.14.0 — 2026-07-21

**운영 토글: `INTRADAY_ENABLED` — 코드 수정 없이 장중 자동매매 on/off.**

## Added

- `LiveSettings`에 `INTRADAY_ENABLED`(기본 false)·`INTRADAY_SCAN_MINUTES`(기본 10) 환경변수 추가.
  운영 서버가 **코드 수정 없이 env로만** 인트라데이 루프를 켤 수 있다. `build_app`이 설정에서 Config를
  구성(`_config_from_settings`)해 엔진·오케스트레이터·스케줄러가 동일 Config를 공유하도록 통일.
- 기본 OFF → 미설정 시 기존 동작(하루 1사이클) 100% 불변.

## Fixed

- `build_app`이 엔진과 오케스트레이터에 서로 다른 `Config()` 인스턴스를 넘기던 잠재 버그를 단일 공유
  Config로 통일(스케줄러가 읽는 `orch.cfg`와 엔진 config 일치 보장).

## 검증

- pytest 371 passed(+5, `_config_from_settings` 토글 테스트), 회귀 0.

## 운영 반영 방법 (요약 — 상세는 README/트레이딩 룰)

1. 서버에서 최신 main pull → 프론트 빌드 → 데몬 재기동.
2. `.env`에 `INTRADAY_ENABLED=1` (선택 `INTRADAY_SCAN_MINUTES=10`) 설정 후 `./dashboard/dashboard.sh restart`.
3. 장중 로그(`dashboard.sh logs live`)로 매수/매도·킬스위치 첫 실동작 관측.
