# v1.15.1 — 2026-07-21

**스캔 상태 스트립 표시 개선: "N분 전" 상대시간 + KST/ET 타임존 라벨.**

## Added

- **상대 시간 "N분 전".** 스캔 상태 스트립에 마지막 스캔이 몇 분 전이었는지를 표시한다
  (방금 전 / N분 전 / N시간 전). 30초마다 갱신되어 데몬이 방금 돌았는지 한눈에 보인다.
- **타임존 라벨 (KST/ET).** 표시되는 시장 벽시계(예: 13:43) 옆에 어느 시장 시간인지 라벨을
  붙인다 — KR→`KST`, US→`ET`. 예: `KR 13:43 KST · 3분 전 · 58/60종목(실패 2) · 게이트통과 3 ·
  매수 1/매도 0 · 다음 ~10분`.

## Changed

- **`/api/scan-status` 에 `tz`·`ts_epoch_ms` 필드 추가.** 스캔 시각은 시장 벽시계(naive)로
  저장돼 있어, 브라우저 타임존과 무관하게 정확한 "N분 전"을 계산하려면 절대 시각이 필요하다.
  백엔드가 저장된 벽시계 시각을 시장 tz(`calendar._TZ`)로 복원해 절대 epoch(`ts_epoch_ms`)와
  tz 라벨을 함께 내려준다. US(America/New_York)는 DST가 반영된다.
