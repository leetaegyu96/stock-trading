# v1.8.0 — 2026-07-10

**감사 Phase A — 신뢰 회복(P0).** Codex 제품 감사(`docs/reviews/2026-07-10-trading-product-audit.md`)의
P0 3건을 해소했다. 핵심은 **"설명과 실제 행동의 완전한 일치"**: 엔진이 내린 결정을 데이터로
영속하고, 화면은 그 데이터를 문구로 변환만 한다(점수 재계산 금지). 여기에 신호 범위의 정직한
고지와 벤치마크·위험조정 성과 표시를 더했다.

설계: `docs/superpowers/specs/2026-07-10-audit-phase-a-trust-design.md`
요구사항 원본: 감사 리포트 §2(P0), §6 1단계 — 완료 조건 3건 모두 충족(시드 대시보드 기준).

## Added

- **결정 이벤트 모델(P0-1)** — `DecisionType`(BUY/PARTIAL_SELL/FULL_SELL/FORCED_SELL)+`trigger_rule`을
  엔진이 결정 시점에 확정: 강제매도 원인 구분(R7 잠금손절/R18 지지선붕괴/R5+R23 급락복합/R10 트레일링),
  등급 부분·전량, 매수 "게이트+N점". 리플레이 DataFrame→라이브 DB→시드→API→프론트 전 계층 영속.
  표시 문구는 영속된 결정 기반: `R5+R23 8점` 강제 전량매도가 이제 "급락 복합조건 → 강제 전량매도"로
  표시된다(기존: "주의 신호 8점" 모순). 출금·상장폐지 매도는 신호 문구를 지어내지 않고 사유로 표시.
- **위험조정 지표(P0-3)** — `metrics.risk_metrics`: CAGR·변동성·Sharpe·Sortino·Calmar(MDD=0→측정불가 0)·
  Profit Factor·평균손익·손익비·기대값/거래·최대연속손실·회복기간(무위험 0 가정). 상세 화면에 지표
  스트립+표본·비용·데이터 꼬리표 툴팁.
- **벤치마크 초과수익(P0-3)** — 리플레이 summary에 benchmark_return/delta/name(국내형=KOSPI200,
  해외형=S&P500, 범용형=양시장 단순평균 "혼합"). `BenchmarkRow` 시드 영속, 성과 표시 1순위=전략 vs
  벤치마크, **미수집 시 숨기지 않고 "벤치마크 미수집" 경고**. "검증됨" 라벨 금지. MDD "최대 낙폭 X%".
  지수 로딩을 하락장 가드 스위치에서 분리(가드 off여도 벤치마크 상시 계산, 매매 무영향).
- **신호 범위 고지(P0-2)** — 화면 라벨 "기술적 매수/매도 신호", "뉴스·공시·수급은 현재 판단에 반영되지
  않음" 상시 고지, 미수집 축(뉴스·공시·수급·거시) "미수집/판단 불가" 레전드.
- **운영 모드·데이터 기준(감사 §4·§5)** — 전 화면 PAPER 모드 배지, `/api/status`(시장별 RunState
  데이터 기준일), WebSocket 연결≠데이터 신선도 구분 표시.
- trading-rules.md §13–15: 결정 유형·표시 매핑·위험지표·벤치마크·라벨 규칙.

## Fixed (리뷰가 발견)

- **라이브 재시작 크래시(Critical, 최종리뷰)** — 대기주문 영속에 결정 필드가 없어 재시작 후 대기 매도
  체결 시 `None.value` 크래시(+P0-1 라벨 소실). `PendingOrder`에 결정 컬럼 추가, persist/rehydrate
  대칭 복원, 크래시 체인 회귀 테스트.
- 1주 보유 부분매도가 반올림으로 전량청산될 때 라벨 PARTIAL→FULL_SELL 승격(설명·수량 일관).
- Calmar가 MDD=0일 때 raw CAGR로 둔갑하던 폴백 제거(측정불가→0). 빈 지수 Series의 `IndexError` 미포착
  수정. API가 미지 decision_type에 500 대신 legacy 문구 폴백.
