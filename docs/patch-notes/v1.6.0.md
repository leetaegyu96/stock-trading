# v1.6.0 — 2026-07-09

**하락장 가드 v2 — 범용형 과발동 해소.** v1.5.0 A/B에서 가드가 범용형에 역효과(한쪽 시장만
하락해도 범용형 전체 신규매수가 차단돼 손실 포지션에 갇힘)를 낸 것을 튜닝했다. 판정 기준을
"지금 시장이 하락장인가"에서 **"캐릭터가 거래하는 모든 시장이 하락장인가"**로 변경 —
국내형·해외형(단일 시장)은 동작 동일, **범용형은 KR·US 양시장 동시 하락일 때만** 차단된다.
기본 OFF(opt-in) 불변.

설계: `docs/superpowers/specs/2026-07-09-bear-guard-v2-design.md`
실험: `docs/experiments/replay_bear_guard_ab_2026-01-09_2026-07-09.md` (3자 비교)

## Changed

- `engine.evaluate_close`: `market_bearish: bool` → `bearish_by_market: dict | None`.
  캐릭터별 `all(시장 하락)` 판정. 기본 None = 가드 미작동(무변경).
- `replay.run_replay`: 스텝당 1회 양시장 하락 dict 계산·전달.
- `docs/trading-rules.md` 하락장 가드 절을 v2 규칙으로 갱신.

  (TWR +16→+27, MDD −11→−6.5)는 그대로 유지.
