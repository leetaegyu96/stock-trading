# v1.7.0 — 2026-07-10

**하락장 가드 튜닝 — 캐릭터별 스위치 + 시장별 MA 기간.** v1.6.0에서 "가드 ON 시 국내형 TWR이
OFF 대비 −8.5%p 손해"로 남았던 후속 과제를 튜닝했다. 가드를 단일 bool·단일 MA 기간에서
**캐릭터별 적용 집합 + 시장별(KR/US) SMA 기간**으로 파라미터화하고, 재현 가능한 스윕/검증
도구로 최적 조합을 탐색했다. 판정식을 공용 헬퍼로 추출해 리플레이·라이브가 동일 로직을
공유하도록 했으며, 라이브 경로에도 가드를 배선했다.

**핵심 결론(정직한 음성 결과):** 6개월 창에서 좋아 보였던 조합(해외형·범용형 on)이 **12개월
확장 검증에서 두 캐릭터 모두 MDD 개선 기준을 통과하지 못했다** — 6개월 결과는 과적합이었고
검증 게이트가 이를 걸러냈다. 사용자 결정에 따라 **기본값은 전체 OFF로 확정**(v1.6.0과 동작
동일). 파라미터화·CLI·라이브 배선·스윕 도구는 인프라로 남아, 향후 국면 판단 시 즉시 opt-in
가능하다. 국내형은 어느 기간에서도 손해라 가드 대상에서 영구 제외 권장 — 원 문제(−8.5%p)는
"국내형에 가드를 걸지 않음"으로 근본 해소.

설계: `docs/superpowers/specs/2026-07-10-bear-guard-tuning-design.md`
실험: `docs/experiments/bear_guard_tuning_sweep_2026-01-09_2026-07-09.md` (스윕 16+1회 + 12개월 검증)

## Changed

- `TradeRules.bear_market_guard: bool` → **`bear_guard_characters: frozenset`** (빈 집합=전체 off).
  가드 차단은 집합에 든 캐릭터에만, 그 캐릭터의 전 시장이 하락장일 때 적용.
- `SignalParams.market_trend_period: int` → **`market_trend_period_kr` / `market_trend_period_us`**
  (시장별 SMA 기간, 각 기본 20).
- `engine.evaluate_close` 가드 게이트를 `st.spec.name in bear_guard_characters` 기준으로 변경.
- CLI: `--bear-guard`(전 캐릭터 강제 on) + **`--no-bear-guard`**(전체 강제 off) 상호배타 그룹.
- `docs/trading-rules.md` §6-1을 캐릭터별·시장별·기본 off 규칙으로 재작성, README 갱신.

## Added

- **`data.make_bearish_fn(indices, periods)`** — 하락장 판정 공용 헬퍼(리플레이·라이브 공유).
  지수 없음/워밍업 NaN/조회 실패 → False 안전 폴백(빈 Series `IndexError` 포함).
- **라이브 가드 배선** — `Orchestrator(index_provider=...)` 주입, `on_close`가 가드 대상이
  있을 때만 양시장 지수로 bearish dict 계산·전달(대상 없음/provider 없음→스킵, 시장별 로드
  실패→그 시장 False). `live/__main__` 기본 provider(`load_index`, 180일 룩백) 배선.
- **`simcore/sweep.py`** (`python -m simcore.sweep`) — KR×US 기간 그리드(16)+OFF(1) 스윕,
  `--validate` 검증 모드, 채택 규칙 자동화(`improves`/`pick_single`/`pick_universal`).

## 검증 (스윕 6개월 + 12개월)

| 캐릭터 | 지표 | OFF 6mo | ON 6mo(후보) | OFF 12mo | ON 12mo | 12mo 판정 |
|---|---|---|---|---|---|---|
| 국내형 | TWR | +38.88% | (off — 모든 기간 손해) | +79.69% | +79.69% | off 유지 |
| 해외형 | TWR/MDD | +16.05% / −10.96% | +26.93% / −6.46% | +15.84% / −12.97% | +14.49% / **−14.68%** | MDD 악화 → off 강등 |
| 범용형 | TWR/MDD | −12.10% / −25.65% | −12.92% / −24.05% | +8.83% / −26.83% | +16.03% / **−28.31%** | MDD 악화 → off 강등 |

- 12개월 검증 기준(`|MDD| 개선 유지 AND TWR ≥ OFF−3%p`)을 두 후보 모두 MDD에서 실패 → 전체 off.
- 기본값 OFF라 리플레이·라이브·대시보드 시드 데이터는 v1.6.0과 동일(재시딩 불필요).

## 알려진 사항 / 후속

- **범용형 라이브 교차시장 as-of 갭**: 라이브는 KR 마감 시점에 US 지수를 조회하므로 US가 당일
  미마감이면 `asof`가 전일 세션을 반환할 수 있어, 범용형을 라이브에서 켤 경우 경계일에
  리플레이와 판정이 어긋날 수 있다(단일시장 캐릭터 무관). 기본 off라 현재 영향 없음 —
  범용형 라이브 활성화 전 점검 필요(`_bearish_by_market` 주석에 명시).
- 가드는 국면 의존적 — 상시 활성화보다 국면 판단 후 opt-in 권장.
