# v1.0.0 — 2026-07-08

**첫 릴리즈.** simcore 백테스트/리플레이 엔진의 기준선(baseline)을 확정하고, 앞으로의 개발을 위한 git 작업 규칙을 정립했다.

## 하이라이트

- 개인 GitHub 저장소(`leetaegyu96/stock-trading`)로 정식 편입.
- 커밋 히스토리 전체를 개인 GitHub 신원으로 정규화(회사 이메일 제거).
- 프로젝트 작업 규칙(`CLAUDE.md`) 정립 — 이후 모든 작업은 이 워크플로를 따른다.

## Added

- **`CLAUDE.md`** — 작업 규칙 문서
  - 논리적 단위 커밋, 모아서 푸시
  - 브랜치에서 개발 (`feature/`, `fix/`, `chore/`)
  - main 아래 SemVer(`vMAJOR.MINOR.PATCH`) 버전업
  - 태그 + 이슈 기반 처리
  - PR 생성·머지 자율 처리 (사용자 승인 최소화)
  - 버전업마다 패치노트 작성
- **`.gitattributes`** — 전 텍스트 파일 LF 고정 (WSL/Windows 혼용 CRLF 노이즈 차단)
- **`CHANGELOG.md`** + **`docs/patch-notes/`** — 버전 이력 체계

## Changed

- 줄바꿈 정규화: 워킹트리에 섞여 있던 CRLF 33개 파일을 LF로 복원 (코드 내용 변경 없음).

## 기준선 구성 (v1.0.0)

| 영역 | 모듈 |

## 알려진 사항

- 로컬 `.venv`는 Windows용이라 WSL에서 pytest 미실행 — 이번 릴리즈는 코드 내용 무변경이라 영향 없음. 추후 Linux venv 셋업 시 CI/테스트 자동화 예정.
