**리서치 후속 3종: 지표 배점 배선 · 워크포워드 최적화(WFO/PBO) · 신호 신뢰도.** 알고 트레이딩 벤처

## Added

- **괴리율·지지저항 신호 배선 (#27)** — v1.11.0에서 라이브러리로만 있던 지표를 신호 코드로 편입:
  G9=저항 돌파(돌파 5pt), G8=괴리율 과매도 반등(모멘텀 3pt), R20=괴리율 과열 확장(변동성 4pt).
  buy_gate 미포함(점수 기여만). 캐시 6개월 리플레이 실측: 발화 확인(G8:147/G9:504/R20:462), TWR 혼합
  (국내형·범용형 개선, 해외형 악화 — 단일 in-sample, 점수/임계값 튜닝은 후속).
- **워크포워드 최적화(WFO) + 과적합확률(PBO) (#30)** — `simcore/walkforward.py`에 폴드별 파라미터
  (buy_score_min) 그리드 최적화(train IS → test OOS 평가)와 López de Prado CSCV 경량 PBO 추가.
  CLI `--wfo`. PBO 극단값 정확 검증(IS최적=OOS최악→1.0, 순위일치→0.0). 완전 CPCV·DSR은 후속(#38).
- **신호 신뢰도 (#31)** — green_score를 도달가능 최대로 정규화한 신뢰도[0,1]를 후보 화면에 표시(read
  전용, 매매 행동 무변경). 규칙기반이라 SHAP 대신 강도 정규화, 고정 익절 타깃은 트레일링 스톱 전략이라
  미제공(정직 라벨링).
