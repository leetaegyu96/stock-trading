# v1.3.0 — 2026-07-09

**신호 시스템 v2 — 점수제·다중 게이팅·트레일링 스탑.** 순수 엔진 계층을 v1의 "청신호 개수
≥ 임계값(7)" 방식에서 **점수제 + 카테고리 상한 + 매수 다중 게이팅 + 매도 등급 + 트레일링
스탑**의 보수적 전략으로 교체했다. 설계 목표는 수익 극대화보다 **손실 최소화**(까다로운 매수,
빠른 매도). 서브프로젝트 4.

설계: `docs/superpowers/specs/2026-07-09-signal-system-v2-design.md`
계획: `docs/superpowers/plans/2026-07-09-signal-system-v2.md`
기준 문서: `docs/trading-rules.md` (v2 전면 재작성, config와 1:1)

## Added

- **신규 기술 지표** (`simcore/indicators.py`): ATR, ADX/DI+/DI−, OBV, 롤링 VWAP,
  Parabolic SAR, 일목균형표(전환·기준·선행스팬 A/B, 구름). 기존 SMA·RSI·MACD·볼린저·스토캐스틱 유지.
- **점수제 신호 판정** (`simcore/signals.py`): 계산형 청신호 17종(G1~G7·G10~G18·G23)·
  적신호 17종(R1~R6·R11~R19·R23·R24) 구현. 차트패턴·피보나치·뉴스·수급(G8·G9·G19·G21·
  G24·G25~30, R20·R22·R25~30)은 명시적 스텁(항상 꺼짐, 후속 구현).
- **카테고리 상한**: 추세10 / 돌파·하락패턴10 / 거래량8 / 모멘텀8 / 변동성6. 계열 과다 가중 방지.
- **매수 다중 게이팅**: 총점 ≥ 18 **AND** 돌파·거래량·추세 각 1개 이상 발화. 관심(12)/후보(15) 등급 표기.
- **매도 등급**: 0~5 보유 / 6~8 주의 / 9~10 부분매도(50%) / 11+ 전량. 부분매도(`portfolio.sell`
  수량 인자) 신규 지원. 강제매도: −7% 손절 · 지지선 붕괴(R18) · 거래량급증음봉+장대음봉(R5+R23).
- **트레일링 스탑** (고정 +15% 익절 대체): 포지션별 최고가·잠금 손절 추적. +10%→본전,
  +20%→+10%, +30%→+20%, +40%→+30%, +40% 초과 시 최고가 대비 −7% 트레일. `TradeReason.TRAILING_STOP`.
- CLI `--buy-score`(매수 최소 총점), 데이터 워밍업 패딩 상향(`LOOKBACK_PAD_DAYS` 120→180, 일목 78거래일).

## Changed

- `SymbolSnapshot`에 `green_score`/`red_score`/`buy_gate`, `Trade`에 `green_score`/`red_score`,
  `Position`에 `peak_price`/`locked_stop_pct` 필드 추가. 리플레이·라이브 스냅샷 생성이 공용
  `signals.snapshot_scores`로 점수·게이트를 채운다.
- 라이브 영속(`simcore/live/db.py`·`repository.py`): 거래·대기주문에 점수 컬럼, 포지션에
  트레일링 상태(peak/locked), 대기매도에 부분매도 플래그를 저장·복원. **기존 DB는 스키마가
  달라지므로 데이터 리셋 필요**(마이그레이션 프레임워크 없음).
- `docs/trading-rules.md` v2 전면 재작성, README 갱신.

## Fixed (구현 중 리뷰가 발견)

- 부분매도가 반올림으로 포지션을 전량 청산할 때 쿨다운이 누락되던 문제(즉시 재매수 가능) —
  실제 청산 여부로 쿨다운 판정하도록 수정.
- **포지션 트레일링 상태(peak/locked_stop)가 DB에 영속되지 않아 라이브 재시작 시 손절
  바닥이 리셋**(원가 이하 포지션이 본전 강제청산)되던 결함 — 최종 전체 리뷰가 발견, 영속·복원 배선 추가.
- 재시작 복구 시 대기주문 위치인자 오프셋(신규 점수 필드 추가 여파) 정정.
- 신호 분포 리포트 라벨을 개수→점수로 정정(v1 잔재 문구 제거).
