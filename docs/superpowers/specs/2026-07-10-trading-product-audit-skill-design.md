# 프로젝트 전용 트레이딩 제품 감사 스킬 설계

## 목적

Claude가 이 저장소의 엔진이나 대시보드를 수정한 뒤 Codex가 코드와 Chrome 실제 화면을 함께 검사하고, 주식 초보자의 학습 목적과 장기적인 제한적 실전 전환 목표에 맞는 피드백을 반복 생성한다.

## 설치 범위

- 경로: `.agents/skills/auditing-trading-product/`
- 적용 범위: 이 저장소 전용
- 호출 예: `$auditing-trading-product 로 Claude 수정 결과를 다시 감사해줘`
- 기본 동작: 읽기·진단·문서 작성. 사용자가 구현을 요청하지 않으면 제품 코드는 수정하지 않는다.

## 기준 실패와 교정

무스킬 기준 세 가지 독립 감사에서 다음 분리가 발생했다.

1. 빠른 대시보드 감사는 화면·반응형·API 정합성을 다뤘지만 전략 성과, 신호 독립성, 실전 안전성을 놓쳤다.
2. 트레이딩 안전성 감사는 데이터·성과·주문 안전성을 다뤘지만 실제 Chrome 화면과 16:9 정보 구조를 놓쳤다.
3. 복기 UX 감사는 와이드 레이아웃과 종목별 매매 여정을 잘 다뤘지만 전략 검증과 운영 안전성을 충분히 연결하지 않았다.

스킬은 세 영역을 하나의 증거 기반 감사 계약으로 묶는다.

## 감사 계약

모든 감사는 다음 순서와 산출물을 갖는다.

1. 저장소 목표, 현재 모드, 최근 변경, 규칙서, 실험 결과를 확인한다.
2. 신호 계산부터 엔진 결정, 저장, API, 화면 문구까지 데이터 흐름을 추적한다.
3. Chrome에서 실제 메인·상세·관련 신규 화면을 확인하고 콘솔·오류·로딩·빈 상태를 점검한다.
4. 16:9 데스크톱 공간 활용, 반응형, 접근성, 정보 위계와 초보자 이해 가능성을 평가한다.
5. 청신호·적신호의 중복 정보, 게이트, 강제결정, 포지션 사이징과 리스크를 평가한다.
6. 벤치마크, 비용, 슬리피지, holdout, walk-forward, point-in-time 데이터와 과적합 위험을 평가한다.
7. PAPER/SHADOW/LIVE 경계를 확인하고 실주문을 현재 기능처럼 가정하지 않는다. 장기 실전 목표에는 별도 진입 게이트를 제시한다.
8. P0/P1/P2, 근거, 영향, Claude 수정 지시, 완료 조건, 재검증 방법을 문서화한다.

## 필수 UX 초점

- 1920×1080을 중심으로 1366×768부터 2560×1440까지 확인한다.
- 과도한 최대폭 제한과 좌우 여백을 측정한다.
- 종목별로 매수·매도 횟수, 실현손익, 현재 보유손익, 종합손익·수익률을 구분한다.
- 한 종목의 진입·추가매수·부분매도·청산을 포지션 생애로 묶는다.
- 가격 차트의 매수·매도 마커와 거래 타임라인을 양방향 연결한다.
- 체결가·수량·신호·수수료·보유기간·결과·반대 근거·복기 노트를 한 흐름에서 확인하게 한다.
- 시각적 장식보다 판단 속도, 정합성, 대비, 키보드 접근, 오류 상태를 우선한다.

## 파일 구성

- `SKILL.md`: 실행 순서, 중단 조건, 산출물 계약
- `references/audit-checklist.md`: 코드·전략·성과·안전·UI/UX 세부 체크리스트
- `references/report-template.md`: Claude 전달용 보고서 구조와 판정 기준
- `agents/openai.yaml`: 프로젝트 UI 메타데이터

반복 실행 스크립트는 두지 않는다. 실행 명령과 서버 구성은 프로젝트가 변할 수 있으므로 매 감사에서 저장소 문서를 기준으로 발견한다.

## 검증

- 폴더 구조와 YAML을 `quick_validate.py`로 검사한다.
- 기준과 동일한 세 시나리오를 스킬과 함께 재실행한다.
- 세 결과 모두 코드, Chrome, 16:9/복기 UX, 신호, 성과 검증, 실전 경계를 빠뜨리지 않아야 한다.
- 실제 브라우저나 실행 환경이 막히면 이를 숨기지 않고 `미검증`으로 분리해야 한다.

## 범위 제외

- 실제 주문 실행 또는 주문 기능 구현
- 수익 보장과 매수·매도 추천
- Claude 대신 제품 코드 수정
- 근거 없는 Apple/Microsoft 스타일 복제

이 스킬의 목적은 멋있다는 인상을 만드는 것이 아니라, 고급 제품 수준의 정보 구조와 검증 가능한 트레이딩 안전성을 반복 감사하는 것이다.
