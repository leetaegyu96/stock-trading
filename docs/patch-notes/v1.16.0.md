# v1.16.0 — 2026-09-02

라이브 6주 손실 사후분석과 그 처방. **적신호 점수 매도를 끄고 손절/트레일만 남기는 모드**를 토글로 추가하고, 운영 계좌를 초기 자본 1억원으로 재시작한다.

## 배경

2026-07-21 ~ 09-02 페이퍼 트레이딩에서 세 계좌 모두 손실로 끝났다(국내형 −3.67% / 범용형 −11.74% / 해외형 −12.30%). 거래 417건과 일봉 8,270행으로 원인을 재구성한 결과:

- **매도 312건 중 276건(88%)이 `INTRADAY_SELL`.** `run_replay`는 `evaluate_intraday`를 호출하지 않으므로 이 경로는 백테스트된 적이 없다. KR 매도는 43건 전부가 장중. 반면 일봉 종가 경로 30건은 흑자(+224 USD).
- **임계 비대칭**: 전량매도 11점(42점 만점의 26%) vs 매수 18점 + 3관문. KR 기준 하루의 56.9%가 전량매도 구간인데 매수 3관문 통과는 3.32%.
- **적신호 동어반복**: R1·R2·R4·R12가 모두 '추세'(cap 10) → 20일선이 깨지면 둘만 켜져도 10점. 여기에 R13(=오늘 종가 < 어제, 4점)이면 14점 → 전량매도.
- **장중 거래량 비교 오류**: `on_intraday`가 당일 *누적* 거래량을 전일 *완성* 거래량·`vol_avg`와 비교 → 장 초반 R13/R24 중 하나가 99.3% 점등, 전량매도 발동률이 마감 50.5% → 장중 61.9%.
- 손실은 전부 점수 매도 구간에 몰려 있다: 9~10점 부분매도 KR **+191만원** / US **+3,154달러**, 11점 이상 전량매도 KR **−673만원** / US **−6,390달러**.

전문: `docs/reviews/2026-09-02-live-loss-autopsy.html`

## Added

- **`TradeRules.signal_sell_enabled`** (기본 `True`) — 점수 기반 매도(`sell_partial_min`=9 / `sell_full_min`=11)의 on/off. `False` 면 **강제매도 4종(R7 손절 · R10 트레일링 · R18 지지선 붕괴 · R5+R23 급락 복합)은 그대로 유효**하고 매수 경로도 영향받지 않는다 — "손절/트레일만" 모드. `docs/trading-rules.md` §7-1. (PR #59)
- **`SIGNAL_SELL_ENABLED` / `MAX_POSITIONS` 환경변수** — 코드 수정 없이 `.env`로 전환(`INTRADAY_ENABLED`과 동일 관용구). `.env.example`에 문서화. (PR #59)
- **손실 사후분석 리포트** `docs/reviews/2026-09-02-live-loss-autopsy.html`. (PR #58)
- 테스트 23건 — 강제매도 4종 생존, 트레일링 래칫 유지, 마감·장중 양 경로 억제, 매수 무영향, env 배선.

## Changed

- **운영 설정 전환** — `INTRADAY_ENABLED=1 → 0`, `SIGNAL_SELL_ENABLED=false`, `MAX_POSITIONS=10`.
- **운영 계좌 초기화** — 상태·이력 테이블을 비우고 콜드스타트로 세 캐릭터에 각 1억원 재시딩. 일봉 캐시(`daily_bars`)·유니버스·KIS 토큰은 보존.

## 검증

같은 유니버스(KR 34 · US 30) 3.2년 리플레이에서 **신규 플래그가 기존 검증 방식(`sell_*_min=999`)과 완전 일치** — 거래 999건/1877건, 수익률·MDD·샤프 소수점까지 동일.

3구간 워크포워드 (`signal_sell_enabled=False` + `max_positions=10`), 9칸 중 수익률 7칸 · MDD 8칸 우세:

| 구간 | 국내형 | 범용형 | 해외형 |
|---|---|---|---|
| 2023-07 ~ 2024-07 | +17.7% → **+28.2%** | +17.4% → **+38.7%** | +28.4% → 23.8% |
| 2024-07 ~ 2025-07 | −1.2% → **+28.8%** | +6.3% → **+12.2%** | +15.6% → −2.3% |
| 2025-07 ~ 2026-09 | +43.5% → **+54.9%** | −20.2% → **+1.7%** | −3.1% → **+21.8%** |

임계값을 13/16/26으로 올리는 튜닝은 캐릭터별로 부호가 뒤집혀 **과적합으로 판단해 채택하지 않았다.**

## 한계

- 같은 유니버스 동일가중 바이앤홀드(KR +412% / US +97%)는 이 구성으로도 넘지 못한다. 백테스트 유니버스에 **생존편향**이 있어 절대 수익률은 부풀려져 있고, **규칙 간 비교**에만 쓸 수 있다. 이 릴리즈는 기존 규칙 대비 개선이지 알파의 증명이 아니다.
- 리플레이는 슬리피지 0·완전 체결을 가정한다. 회전이 높은 기존 규칙일수록 이 가정의 혜택을 크게 받으므로 실제 격차는 표보다 더 벌어진다.
