# v1.11.0 — 2026-07-21

**장중 자동매매 루프(인트라데이).** 24시간 라이브 페이퍼 서버가 장 시간 중 10분마다 유니버스를
스캔해, 기존 신호 배터리와 체결강도로 **현재가 즉시 매수·매도**한다. 마감 1사이클(마감 결정 →
다음 개장 체결)만 하던 기존 동작에 더해, 장중에 기회를 포착해 하루에도 여러 번 사고팔 수 있다.
엔진 결정 규칙은 그대로 재사용하며(관찰≠행동 원칙 유지), 전 경로는 `intraday_enabled` 플래그로
격리 — 기본 OFF면 기존 동작·리플레이 등가성·전체 테스트가 100% 불변이다.

설계: `docs/superpowers/specs/2026-07-20-intraday-trading-loop-design.md`
계획: `docs/superpowers/plans/2026-07-20-intraday-trading-loop.md` (9태스크)

## Added

- **장중 실행 루프** — `Orchestrator.on_intraday`(10분 주기, 장 시간 가드): 유니버스 현재가+당일
  누적거래량으로 **잠정 일봉**(확정 히스토리 d-1 + 인메모리 오늘 봉: 시가·고저 러닝·종가=현재가)
  구성 → `evaluate_frame`로 기존 신호 재평가 → `Engine.evaluate_intraday`가 **현재가 즉시 체결**.
  체결은 기존 `_buy`/`_sell` 경유라 수수료·세금·슬리피지가 정직하게 반영된다.
- **신규 지표(라이브러리)** — `indicators.disparity`(가격괴리율), `support_resistance`(지지/저항선).
  현재는 함수·config만 존재하며 `evaluate_frame` 배점에는 아직 배선되지 않았다(follow-up).
- **체결강도 게이팅** — `KisClient.execution_strength`(KR `cttr`, US 미지원 → None). 매수는 체결강도
  매수우위일 때만 통과, 값 없으면 이 조건만 스킵하고 기존 신호로 판단.
- **휩쏘 방지·킬스위치** — 종목당 하루 매수/매도 각 3회, 재매수 쿨다운 30분(손절·트레일·강제청산
  예외), 당일 손익 −5% 도달 시 그날 신규 매수 중단(매도는 계속).
- **대시보드·문서** — 장중 체결 `INTRADAY_BUY/SELL` 칩 라벨(거래내역·필터), trading-rules §17.

## Fixed / Safety (리뷰가 발견)

- 장중 잠정봉이 KIS 장중 미완성 일봉을 당일 확정봉으로 DB에 저장해 마감 `on_close`가 스테일 가격을
  확정 종가로 굳히던 오염 경로 — 확정 히스토리를 d-1까지만 조회·캐시하도록 수정(오늘 봉은 인메모리).
- 스케줄러 병렬 잡(손절 틱·장중 스캔)이 락 없이 같은 엔진 상태를 동시 변경하던 문제 — 오케스트레이터
  RLock으로 상태변경+영속 구간만 직렬화(네트워크 조회는 락 밖 → 손절 틱을 굶기지 않음).
- `on_intraday` per-symbol 예외·빈 히스토리 볼륨 폴백 크래시 가드(부분 실패 스킵), 엔진 매도 루프
  KeyError 방어.

## 알려진 사항 / 후속 (이슈화 예정)

- 휩쏘 캡·킬스위치 기준이 인메모리 상태라 **장중 프로세스 재시작 시 리셋**된다(당일 카운트·−5% 기준).
- 신규 지표(괴리율·지지저항) 배점 배선 미완(라이브 경로 미호출).
- KIS 체결강도 `cttr` 필드는 문서 기반이라 실서버 응답 검증 전제.
- 운영 활성화: `intraday_enabled=True`로 켠 뒤 첫 장중 실동작·킬스위치 로그 관측 필요.
