# v1.10.0 — 2026-07-20

**의사결정판 가격 가시성 + 라이브 데몬 상시 운영 + 서브패스 배포.** v1.9.0(감사 Phase B) 이후
dev에 누적된 실사용 개선 묶음. 첫 화면 의사결정판에 종목별 가격을 노출해 판단 맥락을 보강하고,
라이브 데몬을 대시보드와 함께 상시 가동하도록 정비했으며(3단계 paper/shadow 운영 시작 기반),
프론트를 서브패스에 배포할 수 있게 했다. 엔진 결정 로직 무변경.

## Added

- **의사결정판 가격 표시** — 오늘의 후보에 종목별 마감가(#10), 오늘의 시장 무버스에 종목별
  가격(#11), 내 캐릭터 베스트·워스트 종목에 가격(#12)을 노출. 사용자가 이름·점수만이 아니라
  실제 가격 맥락에서 후보/보유를 읽을 수 있게 함.
- **라이브 데몬 상시 운영** — `dashboard.sh start`가 백엔드와 라이브 데몬을 동시 기동하고
  `stop`이 함께 종료(#13). 시드가 RunState에 마지막 마감일을 기록해 데몬 재기동 시 갭 리플레이가
  끊김 없이 이어짐(catch-up 연속성). PAPER 모드, 실주문 없음 — 감사 로드맵 3단계 paper/shadow
  운영이 이 릴리즈부터 사실상 상시 진행.
- **프론트 서브패스 배포 지원** — `VITE_BASE_PATH` 환경변수로 하위 경로 배포(#15), React Router
  `basename` 연동(#16). 리버스 프록시 하위 경로 뒤에 대시보드를 올릴 수 있음.

## Fixed

- **KIS 해외 API 클래스주 티커 매핑**(#17) — 유니버스에 `BRK-B`(하이픈)로 저장된 클래스주가 KIS
  해외 API가 요구하는 `/` 구분자(`BRK/B`)와 불일치해 일봉·현재가 조회가 항상 실패, 보유 종목의
  마감가·적신호가 직전값 승계로만 유지되고 라이브 시세도 stale 폴백에 빠지던 문제. `kis_client`
  심볼 정규화(`-`→`/`) 추가로 수정, 테스트 3건 추가.
- **평균손실 표기 부호 정정**(#10) — 평균손실이 `+₩`로 표기돼 이익으로 오인될 수 있던 것을 손실
  부호로 정정.
