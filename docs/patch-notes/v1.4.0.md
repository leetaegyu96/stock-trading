# v1.4.0 — 2026-07-09

**대시보드 UI 개편 + 데이터 리셋 — 초보 친화 일일 현황판.** 서브프로젝트 5. 순수 엔진/신호
판정 로직은 변경하지 않고(리플레이 결과 노출 필드 추가만), 표시·조회·시딩 계층을 개편했다.
주식 완전 초보도 이해할 수 있는 화면을 목표로, v1.3.0의 신호 v2 6개월 결과를 실제로 보여준다.

설계: `docs/superpowers/specs/2026-07-09-dashboard-ui-v2-design.md`
계획: `docs/superpowers/plans/2026-07-09-dashboard-ui-v2.md`

## Added

- **종목명 표시** (`simcore/names.py`): 코드→한글/회사명 정적 매핑(KR 34·US 34), 미스 시 코드 폴백.
  보유종목·거래내역·현황판·출금 청산목록에서 "005930" 대신 "삼성전자"로 표시.
- **초보 친화 신호 표시** (`simcore/signal_display.py`): 신호 코드(G1·R3…)를 한글명·별점(★)·
  등급(A/B/C/D)·한 줄 요약으로 변환. 예) "골든크로스 + 신고가 돌파 + 거래량 급증 → 강력
  매수 신호 (24점/B등급)". 거래내역은 요약 + 펼치면 개별 신호 이름·별점.
- **일일 현황판 메인 화면**: 좌측 3캐릭터 카드 열 + 우측 현황판 — 오늘의 시장(추적 유니버스
  상승/하락 top5)·내 캐릭터 요약(오늘 손익·보유수·베스트/워스트)·최근 체결. 카카오뱅크·토스류.
- **`/api/dashboard`** 엔드포인트: 시장 movers·캐릭터 포트폴리오 요약·최근 체결.
- **`dashboard/scripts/seed_from_replay.py`**: 6개월 리플레이 결과를 DB에 적재하는 리셋
  스크립트(`--force` 가드, `--force` 시 스키마 drop/recreate로 자립). `ReplayResult`에 최종
  포지션·현금·last_close 노출(`simcore/replay.py`).
- `dashboard/backend/constants.py`: `FALLBACK_FX_RATE` 단일 출처(대시보드·시드 공유).

## Changed

- 상단바에서 "simcore / 모의투자" 브랜드 텍스트 제거(전체자산·실시간 표시만 유지).
- 거래/보유 응답에 `name`·`green_score`·`red_score`·`signal_summary`·`signal_detail` 병합.
- 상승=빨강/하락=파랑 팔레트·라이트/다크 유지. 청신호=🟢/적신호=🔴(용어축).
- 라이브 영속 ORM(`simcore/live/db.py`)의 배열 컬럼에 sqlite 변형(JSON) 추가 — Postgres 경로 불변.

## Fixed

- **범용형 총자산 불일치(사용자 보고 버그) 해소**: 카드 총자산과 자산곡선 마지막값이 서로 다른
  값(4,100만 vs 1억08)으로 보이던 문제 — 데모 시드의 자산곡선/포지션 불일치가 원인이었다.
  리플레이 최종 스냅샷(포지션+현금)에서 자산곡선을 산출하고, 조회 시점 환율(1300)로 정합해
  **3캐릭터 모두 카드 총자산 = 자산곡선 마지막값 정확히 일치**(재시딩으로 검증).
- 자산곡선을 조회 환율 비율로 전체 스케일링 → USD 보유 캐릭터의 "오늘 %"가 환율 베이스 차이로
  왜곡(가짜 −14%)되던 것을 실제 일간수익률로 교정.
- 시드 CLI가 리플레이 실제 환율로 최종 자산을 재계산하던 문제를 대시보드 고정 환율로 통일.
