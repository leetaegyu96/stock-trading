# v1.12.0 — 2026-07-21

**전략 검증(워크포워드) + 장중 가드 영속.** 감사 로드맵 3단계(실전 전 필수 전략 검증)의 첫 구현으로
롤링 아웃오브샘플 검증 하니스를 추가하고, v1.11.0 인트라데이의 안전 결함(재시작 시 킬스위치·휩쏘 캡
리셋)을 수정했다. 알고 트레이딩 벤처 리서치 결과와 채택 근거도 함께 기록.

## Added

- **워크포워드(롤링 OOS) 검증 하니스** (`simcore/walkforward.py`) — 전체 구간을 롤링 폴드로 나눠 각
  test 구간을 **아웃오브샘플로 독립 평가**하고, 폴드별 지표(TWR·MDD·Sharpe·승률·거래수)와 폴드 간
  일관성(평균·표준편차·수익 폴드 비율·최악 MDD)을 리포트한다. 기존 `run_replay`+`risk_metrics`
  재사용(신규 의존성 0), 인과적 신호라 lookahead 없음, 폴드마다 콜드스타트. CLI 포함. trading-rules §18.
  - 정직한 범위: 폴드별 재적합 없는 롤링 OOS 평가(진짜 WFO·CPCV·PBO/Deflated Sharpe는 후속 #30).
- **알고 트레이딩 벤처 리서치** (`docs/research/2026-07-21-algo-trading-ventures.md`) — QuantConnect·
  Numerai·Kavout·Tickeron·Alpaca·KIS 등 조사(deep-research 108 에이전트·적대적 검증), 이식 아이디어
  우선순위·난이도표와 채택 결정.

## Fixed / Safety

- **장중 가드 영속 (#26)** — 킬스위치 기준선(당일 시작자산)·휩쏘 캡 카운터가 인메모리라 24시간 데몬이
  장중 재시작되면 리셋되던 안전 결함 수정. 신규 `intraday_guards` 테이블에 매 틱 저장하고 부팅 시 복원 →
  재시작해도 당일 −5% 킬스위치·종목당 3회 캡이 유지된다.
