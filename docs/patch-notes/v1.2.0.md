# v1.2.0 — 2026-07-08

**서브프로젝트 3: 대시보드 (FastAPI + React + WebSocket).**

라이브 모드가 PostgreSQL에 쌓는 3캐릭터 데이터를 눈으로 보는 대시보드. 하이브리드 UX —
메인은 캐릭터 카드로 요약, 클릭하면 진지한 상세(차트·표·지표)로 진입. 순수 엔진(`simcore/`)과
라이브 계층(`simcore/live/`)은 한 줄도 변경하지 않고 재사용했다(기존 테스트 무손상).

## 하이라이트

- **드디어 화면.** 로컬에서 `uvicorn`이 React 빌드 + REST + WebSocket을 단일 프로세스로 서빙.
- **성과연동 표정 캐릭터 아바타** — 국내형/해외형/범용형이 각자 얼굴(커스텀 SVG)을 갖고,
  수익이면 활짝 웃고 손실이면 시무룩. "캐릭터"가 살아있다.
- **실시간** — FastAPI가 Postgres를 주기 폴링해 WebSocket으로 카드/보유종목을 밀어준다(라이브
  데몬과 디커플 — 데몬이 꺼져 있어도 마지막 상태 표시).
- **입출금 버튼** — 대시보드에서 입금/출금 예약(`flow_requests`), 다음 개장에 데몬이 반영.

## Added — 백엔드 `dashboard/backend/`

| 모듈 | 역할 |
|------|------|
| `app.py` | FastAPI: REST + WebSocket `/ws` + React 정적 서빙(SPA 폴백, path-traversal 가드) |
| `queries.py` | Postgres 읽기(캐릭터/포지션/거래/입출금/자산곡선/현금) |
| `summary.py` | 카드/상세 집계 + TWR·MDD·승률 (`simcore.metrics` 재사용, 자산곡선 일단위 정규화) |
| `live_prices.py` | KIS 현재가 병합(실패 시 daily_bars 폴백, stale 표시) — `DbTokenStore` 공유 캐시 |
| `flows.py` | 입출금 예약(`enqueue_flow`, 입금+/출금−·청산지정, 검증) |
| `broadcaster.py` | WebSocket 연결관리 + 폴링 diff 브로드캐스트 |

- REST: `GET /api/characters`(카드), `/{name}`(지표), `/equity`·`/positions`·`/trades`·`/flows`,
  `POST /{name}/deposit|withdraw`.
- 대시보드는 **읽기 전용 + `flow_requests` INSERT만** — 매매/상태 변경은 라이브 데몬 소관.

## Added — 프론트엔드 `dashboard/frontend/` (Vite + React + TS)

- 메인: 리치 캐릭터 카드 3개(아바타·TWR·총자산·오늘등락·30일 스파크라인·보유/현금·벤치대비),
  WebSocket 실시간 갱신, 클릭 → 상세.
- 상세: 자산곡선 차트(기간 토글)·보유종목 테이블(실시간가·손익·지연배지)·거래내역(청/적신호 배지)·
  성과지표 패널·입출금 모달(접근성 dialog).
- `Avatar`(성과 표정), `mood.ts`(비율→퍼센트 단위계약), `format.ts`(원/% 포맷) — 순수 함수 vitest.
- 상승=빨강/하락=파랑(한국 관례), 라이트/다크. 자체 인라인 SVG(외부 자산/CSP 리스크 없음).

## Fixed (구현 중 코드리뷰가 발견·수정)

1. **DB 엔진 누수** — `session_factory()`가 호출마다 새 엔진(QueuePool)을 만들어 dispose하지
   않아 요청/폴링마다 연결이 새던 문제 → `@lru_cache` 싱글턴으로 1회 생성·재사용.
2. **CardSummary 식별 필드 누락** — 카드가 어느 캐릭터인지 식별 불가 → name/base_currency/markets 추가.
3. **자산곡선 일단위 정규화** — `equity_curve.ts`(datetime) vs `capital_flows.date`(date) 불일치로
   TWR가 조용히 왜곡되던 문제 → 하루 단위로 정규화(replay 관례와 일치).

  KIS 토큰 공유/상승빨강) 검증, N1 수정 후 머지.

## 알려진 사항 / 후속 과제

- `benchmark_delta`는 아직 미계산(카드에 "—" 표시) — 지수 수익률 조달 필요.
- US 세션 마감 equity가 서버(KST) 벽시계로 기록돼 US측 입출금 근처 TWR가 ±1일 어긋날 수 있음 —
  근본 해결은 `simcore/live`에서 EquityPoint에 세션 거래일 저장(별도 과제).
- 신선한 DB(테이블 없음)에서 조회 시 500 → `[]`/503 degrade 개선 여지(create_all은 읽기전용 위반이라 지양).
- 뮤테이션 엔드포인트 무인증 — 로컬/개인용 단일 오리진 전제.
