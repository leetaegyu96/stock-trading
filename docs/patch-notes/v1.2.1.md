# v1.2.1 — 2026-07-09

**대시보드 UI 전문가급 개편.** 프론트엔드 전용 개선이며 백엔드·순수 엔진·라이브 계층은
한 줄도 바뀌지 않았다(API·데이터 계약 동일, Python 137 테스트 무손상).

## 목표

"트레이딩 전문가가 봐도 그럴싸하다"는 인상을 주는 화면. 기존 기능(요청 사항)은 모두
유지하되, 시각 완성도·정보 위계·차트 전문성을 끌어올렸다.

## Changed — 디자인 시스템

- **팔레트**: dataviz `validate_palette.js` 검증을 통과한 상승=빨강/하락=파랑 쌍
  (라이트 `#d6303c`/`#2563eb`, 다크 `#f2545b`/`#5b8def` — CVD ΔE>70, 대비 ≥3:1).
  라이트·다크 각각 별도 스텝, 서피스 대비 검증.
- **타이포·숫자**: 시스템 산세리프 스택, 모든 수치는 등폭(tabular-nums)로 표·지표 정렬.
- **공용 컴포넌트**: 버튼(primary/outline/ghost)·칩(up/down/neutral)·세그먼트 토글,
  앱 셸(중앙 정렬 1264px)·상단바(브랜드·전체자산·실시간 연결 점).

## Changed — 화면

- **메인 카드**: 총자산을 히어로 숫자로, 오늘 등락은 칩으로, 30일 추이는 그라디언트 영역
  스파크라인으로. 수익률(TWR)·누적손익 2열 배치, 보유·현금·벤치 대비 푸터.
- **자산곡선 차트** (전면 재작성): Y축 눈금(억/만 축약)·수평 그리드·기간 시작 기준선(점선)·
  X축 날짜 눈금·**크로스헤어 + 툴팁**(포인터 X에 가장 가까운 데이터로 스냅, 값·기간대비 표기)·
  기간 토글(1M/3M/6M/전체). `ResizeObserver`로 컨테이너 실측 폭에 픽셀 단위 렌더(비율 왜곡 없음).
- **보유종목/거래내역 테이블**: 숫자 우측정렬·등폭, **시장 통화 인지 표기**(KR ₩ 정수 / US $ 소수),
  KR/US 시장 태그, 청/적 신호 배지(G*/R*), 사유 한글 라벨(신호 매수·손절·익절), 시세 지연 배지.
- **성과지표 스트립**: TWR·MDD·누적손익·거래 횟수·승률을 한 줄 지표 스트립으로.
- **아바타**: 표정(활짝/미소/무표정/시무룩) 및 링 다듬기, 캐릭터 정체성 배지 유지.
